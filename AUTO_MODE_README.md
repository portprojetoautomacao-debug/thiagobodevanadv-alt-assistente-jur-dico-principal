## 🚨 Troubleshooting

### Se algo não iniciar automaticamente:
1. Execute: `Ctrl+Shift+P` → "Developer: Reload Window"
2. Ou execute manualmente: `Terminal → Run Task → auto-init`

### Se o servidor não iniciar:
```bash
npm run dev
```

### Se testes não rodarem:
```bash
npm run test
```
