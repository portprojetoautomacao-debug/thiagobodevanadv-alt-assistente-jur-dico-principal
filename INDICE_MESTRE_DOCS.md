## ⚡ QUICK COMMANDS (Comandos Rápidos)

### Testar Sistema Python Localmente

```bash
# Navegar para diretório
cd streamlit-app

# Setup completo (primeira vez)
./setup-all.sh

# Editar .env com suas credenciais
nano .env

# Executar tudo
./run-all.sh

# Acessar:
# Backend: http://localhost:8000
# Docs: http://localhost:8000/api/docs
# Streamlit: http://localhost:8501
```

### Executar Apenas Backend Python

```bash
cd streamlit-app/backend
./run-backend.sh

# Ou manualmente:
python main.py
```

### Executar Apenas Streamlit

```bash
cd streamlit-app
./run.sh

# Ou manualmente:
streamlit run app.py
```

### Testar Compatibilidade Node.js vs Python

```bash
# Node.js (produção)
curl https://assistente-juridico-github.vercel.app/api/health

# Python (local)
curl http://localhost:8000/api/health

# Comparar estrutura JSON
diff <(curl -s NODE_URL | jq -S '.') <(curl -s PYTHON_URL | jq -S '.')
```
